Developer guide

Penora template documentation.

This guide explains the static template structure and the main customization points.

1. Installation

Unzip the package and open index.html. For best testing, run the folder through a local static server such as the VS Code Live Server extension.

2. Folder structure

penora-stationery/
├── index.html, index-2.html, shop.html …
├── assets/
│   ├── css/
│   ├── js/
│   ├── icons/svg/
│   └── images/{hero,products,categories,banners,blog,general}/
├── documentation/
├── README.md
├── sitemap.xml
└── robots.txt

3. Pages

Two distinct homepages, catalogue and category pages, product details, new arrivals, bulk enquiries, brand and contact pages, journal pages, pricing information and standalone account and utility pages are included.

4. Colors and typography

Update CSS custom properties in assets/css/style.css. Palette: forest green #245451, muted gold #C47C59, warm paper cream #F3EDE2. The font families are DM Serif Display and Inter.

5. Product data and JPG images

Product records are in assets/js/products.js. Replace local JPG images in assets/images/ and keep their paths accurate. Banner images live in assets/images/banners/.

6. SVG icons

Reusable SVG interface icons are stored in assets/icons/svg/. Replace an icon file while keeping its name, or update the corresponding image path.

7. Catalogue filters

Update category IDs and product attributes in products.js. Category, product-type, brand, price, availability and sorting logic is in filters.js. The same file renders product detail galleries and the journal search, category filter and Load More control.

8. Dark/light mode and RTL

Theme preference is stored in localStorage as theme (light or dark, falling back to the visitor's prefers-color-scheme) and direction as dir (ltr or rtl). A small inline script in each page's <head> applies both before first paint to avoid a flash. Stylesheets must load in this order: style.css, professional-refinements.css, dark-mode.css, rtl.css, responsive.css.

9. Cart and quick view

The slide-over cart lives in main.js and is stored in localStorage under penora-cart. Any button with data-add-to-cart plus data-id, data-name, data-price and data-image adds a line; data-quick-view opens the quick-view dialog; links with data-bulk-order carry the bag into the bulk enquiry form. The demo tax rate is window.PENORA_TAX_RATE in products.js. Checkout is a demonstration only and collects no payment.

10. Forms and integrations

Bulk and contact forms use client-side validation and demonstration success messages. Connect them to Formspree, Netlify Forms or your own backend before collecting real submissions. Newsletter forms are also front-end demonstrations. No credentials or API keys are included.

11. Third-party resources

Fonts are loaded from Google Fonts (DM Serif Display and Inter). No icon-font package or external image host is required. Photography is stored locally as JPG.

12. Changelog

Version 1.0 — initial responsive catalogue and enquiry-based template. Version 1.1 — slide-over cart with quick view, theme and direction applied before first paint, dark-mode icon and contrast fixes, and layout alignment refinements.

13. Support

Replace the sample Penora support details in the footer and contact page with your own business information before publishing.
