# Penora — Stationery & Office Supplies HTML Template

A responsive, enquiry-led stationery and office supplies storefront built with HTML5, CSS3 and vanilla JavaScript.

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static web server. No build step is required.

## Main pages
`index.html`, `index-2.html`, `shop.html`, `categories.html`, `product-details.html`, `new-arrivals.html`, `bulk-orders.html`, `about.html`, `contact.html`, `blog.html`, `blog-details.html`, `pricing.html`, `login.html`, `register.html`, `404.html`, `coming-soon.html`.

## Important notes
- Forms show client-side validation and confirmation states but are not connected to a real email service or backend.
- Login and registration are visual interfaces only; no authentication is implemented.
- Product, price, brand, company and editorial content is editable sample data.
- Photographic assets are local JPG files. Interface icons are SVG files in `assets/icons/svg/`.
- Brand palette: `#245451`, `#C47C59`, `#F3EDE2`. Typography: DM Serif Display and Inter.
- Theme and RTL preferences are stored in localStorage.

See `documentation/documentation.html` for customization and integration guidance.
